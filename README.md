# Zinhtech Academy JavaScript Assignment

## Overview

This repository contains my JavaScript assignment completed during the Zinhtech Academy June-November Cohort.

The assignment consists of five interactive JavaScript projects designed to help me practise JavaScript fundamentals, DOM manipulation, events, functions, and user interaction.

## Projects

### 1. The Color Changer
A simple interactive project that demonstrates how JavaScript can be used to change colours on a webpage based on user interaction.

### 2. Light and Dark Mode
A theme-switching project that demonstrates how JavaScript can be used together with CSS to switch between light and dark modes.

### 3. Live Typing Counter
A project that tracks what the user types and displays the character count in real time.

### 4. Key Spy
A keyboard interaction project that detects keys pressed by the user and displays information about the keyboard event.

### 5. The Welcome Form
A form-based project that collects user information and uses JavaScript to respond to the user's input.
